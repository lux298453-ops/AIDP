# 字节跳动 (ByteDance) 设计风格规范

> 算法彩虹·内容宇宙·激发创造，主色 #161823

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **激发创造**：降低创作门槛，让每个人都能成为内容创作者
- **算法驱动**：内容分发以用户兴趣为核心，界面服务于信息流效率
- **多元包容**：尊重多元内容生态，设计不预设单一审美标准
- **极致体验**：追求流畅的沉浸式体验，减少一切干扰与摩擦

### 1.2 设计原则
1. **内容优先**：界面退居幕后，让内容成为绝对主角
2. **沉浸流畅**：全屏沉浸式浏览，手势操作丝滑无断点
3. **即时反馈**：每个操作都有即时视觉/触觉反馈
4. **个性化**：尊重用户偏好，支持深度个性化定制
5. **无障碍**：确保不同能力用户都能顺畅使用

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #0C0C14 |
| 卡片/容器 | #FFFFFF | #1A1A2E |
| 主文字 | #212121 | #E0E0E0 |
| 辅助文字 | #757575 | #8C8C8C |
| 占位文字 | #9E9E9E | #5A5A6E |
| 分割线 | #E0E0E0 | #2A2A3E |
| 品牌主色 | #161823 | #3A3A5C |
| 强调红 | #FE2C55 | #FF4D6D |
| 错误色 | #FF1744 | #FF5252 |
| 警告色 | #FFB300 | #FFD54F |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E0E0E0
2. 禁止暗色模式下品牌深色主色需提亮为#3A3A5C保证可识别性
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#0C0C14保持层次感
5. 禁止渐变色在暗色模式下降低饱和度，应保持色彩活力

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 全屏视频/内容浏览时UI控件必须自动隐藏，3秒无操作触发
2. 所有交互操作必须提供即时触觉反馈（轻触振动）
3. 双击点赞必须配合心形粒子动画
4. 评论输入框必须固定于底部，键盘弹出不遮挡内容
5. 下拉刷新必须使用品牌定制动画

### 禁止做
1. 禁止在信息流中插入不可跳过的全屏广告
2. 禁止使用模态弹窗阻断用户浏览流程
3. 禁止底部标签栏超过5个入口
4. 禁止在视频播放界面叠加超过3个操作按钮
5. 禁止使用低对比度文字影响内容可读性
