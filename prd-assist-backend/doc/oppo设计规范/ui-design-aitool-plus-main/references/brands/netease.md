# 网易 (NetEase) 设计风格规范

> 态度红·有态度·匠心内容，主色 #C10A0A

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **态度鲜明**：设计传递网易独特的态度与立场，不做平庸产品
- **匠心内容**：设计服务于优质内容呈现，让内容成为核心
- **社区氛围**：构建有温度的社区互动体验，用户参与感强
- **品质追求**：每个细节都追求品质感，拒绝粗制滥造

### 1.2 设计原则
1. **内容为王**：界面退居幕后，让内容成为视觉焦点
2. **态度表达**：在关键节点注入品牌态度，不做无性格设计
3. **阅读舒适**：排版优先考虑阅读体验，长文内容舒适可读
4. **互动有温度**：评论与互动设计体现社区温度
5. **品质细节**：每个像素都经得起推敲，细节决定品质

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1A1A1A | #E6E6E6 |
| 辅助文字 | #666666 | #8C8C8C |
| 占位文字 | #999999 | #595959 |
| 分割线 | #EBEBEB | #2E2E2E |
| 品牌主色 | #C10A0A | #E03333 |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |
| 信息色 | #1890FF | #4096FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E6E6E6
2. 禁止暗色模式下品牌红直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止长文阅读在暗色模式下降低行高，必须保持宽松行高

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 文章正文行高必须不小于1.75倍字号，保证阅读舒适
2. 评论区域必须支持盖楼式展示
3. 内容详情页必须提供字号调节功能
4. 新闻列表必须展示来源与时间信息
5. 视频播放器必须支持弹幕开关

### 禁止做
1. 禁止在主按钮上使用品牌红以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰阅读体验
4. 禁止正文段落字号小于14px
5. 禁止在文章正文中插入不可关闭的弹窗广告
