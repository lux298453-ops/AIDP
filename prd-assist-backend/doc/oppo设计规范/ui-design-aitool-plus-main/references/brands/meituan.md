# 美团 (Meituan) 设计风格规范

> 生活黄·吃喝玩乐·即时送达，主色 #FFD100

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **生活服务**：设计围绕"吃喝玩乐"本地生活场景，贴近日常
- **即时满足**：强调即时配送与即时服务，设计传递速度感
- **温暖友好**：品牌黄色传递温暖与活力，让生活更有滋味
- **简单好用**：降低使用门槛，让所有用户都能轻松点单

### 1.2 设计原则
1. **场景驱动**：根据不同生活场景设计专属交互模式
2. **效率优先**：从选店到下单路径最短，3步完成点单
3. **信息清晰**：商家信息、配送时间、价格信息一目了然
4. **情感连接**：骑手与用户的情感化设计，传递温度
5. **本地化**：适配不同城市特色与本地消费习惯

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #FAFAFA | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1A1A1A | #E8E8E8 |
| 辅助文字 | #8C8C8C | #8C8C8C |
| 占位文字 | #BFBFBF | #595959 |
| 分割线 | #E8E8E8 | #2E2E2E |
| 品牌主色 | #FFD100 | #FFE082 |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |
| 信息色 | #1890FF | #4096FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E8E8E8
2. 禁止暗色模式下品牌黄直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止配送状态色在暗色模式下降低对比度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 配送时间必须醒目显示，字号不小于14px
2. 商家评分必须使用星级+数字双重展示
3. 下单按钮必须固定在页面底部
4. 配送进度必须提供实时地图追踪
5. 搜索框必须支持语音输入

### 禁止做
1. 禁止在主按钮上使用品牌黄以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰点单流程
4. 禁止商家列表隐藏配送费信息
5. 禁止在配送追踪页面使用静态图片代替实时地图
