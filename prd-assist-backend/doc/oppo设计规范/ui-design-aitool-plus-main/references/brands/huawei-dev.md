# 华为 (Huawei) 设计风格规范

> 全场景红·科技自立·智慧全连接，主色 #CF0A2C

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **全场景智慧**：1+8+N全场景生态，设计覆盖手机、平板、手表、车机等全终端
- **科技自立**：鸿蒙原生设计语言，体现自主技术美学
- **人因设计**：基于人因工程学研究，确保舒适与高效
- **无障碍优先**：从设计源头保障无障碍体验

### 1.2 设计原则
1. **和谐统一**：跨设备视觉与交互一致，一套设计语言适配全场景
2. **清晰高效**：信息层级清晰，操作路径最短，减少认知负荷
3. **自然直觉**：交互方式符合物理世界认知，手势操作自然流畅
4. **情感关怀**：在关键节点注入温度，让科技更有温度
5. **安全可靠**：隐私与安全融入设计，用户数据可视可控

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F1F3F5 | #1A1A1A |
| 卡片/容器 | #FFFFFF | #2A2A2A |
| 主文字 | #1A2129 | #E5E8EB |
| 辅助文字 | #666C73 | #8C9299 |
| 占位文字 | #8C9299 | #5A5A5A |
| 分割线 | #E5E8EB | #3A3A3A |
| 品牌主色 | #CF0A2C | #E61D48 |
| 错误色 | #E84026 | #FF6347 |
| 警告色 | #E6A200 | #FFB800 |
| 信息色 | #0A59F7 | #3B7DFF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E5E8EB
2. 禁止暗色模式下品牌红直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#1A1A1A保持层次感
5. 禁止跨设备流转动画在暗色模式下丢失品牌色辨识度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 所有交互必须支持手势操作（滑动、长按、双击）
2. 跨设备流转必须提供视觉连续性动画
3. 表单输入必须提供实时校验与错误提示
4. 页面必须支持鸿蒙系统级返回手势
5. 图标必须使用HarmonyOS统一图标库

### 禁止做
1. 禁止在主按钮上使用品牌红以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰用户操作流程
4. 禁止底部标签栏图标超过5个
5. 禁止在折叠屏适配时拉伸图标，必须重新布局
