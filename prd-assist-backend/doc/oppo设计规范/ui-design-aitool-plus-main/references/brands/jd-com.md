# 京东 (JD.com) 设计风格规范

> 品质红·多快好省·信赖之选，主色 #E2231A

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **品质信赖**：设计传递正品保障与品质信赖感，让用户放心购买
- **多快好省**：界面服务于"多快好省"核心商业价值
- **效率至上**：缩短从浏览到下单的路径，提升转化效率
- **数据驱动**：设计决策基于A/B测试与数据验证

### 1.2 设计原则
1. **清晰可辨**：商品信息层级清晰，价格与促销信息突出
2. **高效转化**：购买路径最短，减少决策摩擦
3. **信赖感**：视觉语言传递正品保障与品质承诺
4. **一致性**：跨端体验统一，Web/APP/小程序保持一致
5. **包容性**：适配全年龄段用户，特别是中老年用户

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F2F3F5 | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1D2129 | #E5E6EB |
| 辅助文字 | #6B7785 | #86909C |
| 占位文字 | #A9AEB8 | #5A5A5A |
| 分割线 | #E5E6EB | #2E2E2E |
| 品牌主色 | #E2231A | #F34F4B |
| 错误色 | #F53F3F | #FF6B6B |
| 警告色 | #FF7D00 | #FF9A2E |
| 信息色 | #3491FA | #5AAFFF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E5E6EB
2. 禁止暗色模式下品牌红直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止促销标签在暗色模式下降低对比度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 商品价格必须使用品牌红突出显示，字号不小于16px
2. 购买按钮必须固定在页面底部，始终可见
3. 促销信息必须使用标签/角标明确标注
4. 商品图片必须支持点击放大查看
5. 搜索框必须位于页面顶部，始终可访问

### 禁止做
1. 禁止在主按钮上使用品牌红以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰购买流程
4. 禁止商品列表单行超过2个商品卡片
5. 禁止价格信息使用与正文相同的字号和颜色
