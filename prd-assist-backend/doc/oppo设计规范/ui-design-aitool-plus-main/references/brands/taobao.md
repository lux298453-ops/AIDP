# 淘宝 (Taobao) 设计风格规范

> 发现橙红·淘你喜欢·万能市场，主色 #FF5000

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **发现乐趣**：设计鼓励探索与发现，"逛"的体验优于"搜"的效率
- **万能市场**：万物皆可淘，设计承载海量商品与多元场景
- **逛感设计**：信息流式浏览体验，让用户沉浸式"逛"淘宝
- **消费决策**：设计辅助消费决策，评价/比价/推荐一目了然

### 1.2 设计原则
1. **逛感优先**：信息流沉浸式浏览，下拉不断发现新内容
2. **商品突出**：商品图片与价格是视觉焦点，UI退居幕后
3. **决策辅助**：评价/销量/优惠信息清晰展示，辅助决策
4. **促销氛围**：大促期间设计氛围感强，日常保持清爽
5. **个性化**：基于用户偏好的个性化推荐与界面定制

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #212121 | #E0E0E0 |
| 辅助文字 | #757575 | #8C8C8C |
| 占位文字 | #9E9E9E | #5A5A5A |
| 分割线 | #E0E0E0 | #2E2E2E |
| 品牌主色 | #FF5000 | #FF6923 |
| 错误色 | #FF1744 | #FF5252 |
| 警告色 | #FFB300 | #FFD54F |
| 信息色 | #2979FF | #448AFF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E0E0E0
2. 禁止暗色模式下品牌橙红直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止商品价格在暗色模式下降低对比度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 商品价格必须使用品牌橙红突出显示，字号不小于16px
2. 购买按钮必须固定在商品详情页底部
3. 促销信息必须使用标签/角标明确标注
4. 商品图片必须支持左右滑动查看多图
5. 搜索框必须位于首页顶部，支持拍照搜索

### 禁止做
1. 禁止在主按钮上使用品牌橙红以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰购买流程
4. 禁止商品列表单行超过2个商品卡片
5. 禁止价格信息使用与正文相同的字号和颜色
