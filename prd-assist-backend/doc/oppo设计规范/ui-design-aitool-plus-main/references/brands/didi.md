# 滴滴 (DiDi) 设计风格规范

> 出行橙·安全到达·一路顺风，主色 #FF7F27

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **安全守护**：设计将安全信息置于最高优先级，行程安全一目了然
- **智能调度**：算法驱动的智能派单，设计呈现效率与精准
- **出行便捷**：从叫车到到达全流程极简，3步完成叫车
- **信任构建**：透明化价格与行程信息，建立用户信任

### 1.2 设计原则
1. **安全可视**：安全功能与信息始终可见，一键触达
2. **路径清晰**：叫车-等待-行程-支付流程清晰无歧义
3. **实时感知**：车辆位置、预计到达时间实时更新
4. **信息透明**：价格、路线、司机信息完全透明
5. **场景适配**：不同出行场景（快车/专车/顺风车）差异化设计

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F7F8FA | #0D0D0D |
| 卡片/容器 | #FFFFFF | #1A1A1A |
| 主文字 | #1F2225 | #E5E5E5 |
| 辅助文字 | #7D828A | #8C8C8C |
| 占位文字 | #A8ADB5 | #5A5A5A |
| 分割线 | #EBEDF0 | #2A2A2A |
| 品牌主色 | #FF7F27 | #FF9955 |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |
| 信息色 | #1890FF | #4096FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E5E5E5
2. 禁止暗色模式下品牌橙直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止地图在暗色模式下使用浅色底图，必须切换暗色地图瓦片
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#0D0D0D保持层次感
5. 禁止安全功能按钮在暗色模式下降低对比度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 安全中心入口必须始终可见，位于首页显著位置
2. 预计到达时间(ETA)必须实时更新，字号不小于18px
3. 叫车按钮必须固定在页面底部，高度不小于48px
4. 行程分享功能必须一键触达
5. 紧急求助按钮必须支持长按触发

### 禁止做
1. 禁止在主按钮上使用品牌橙以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰叫车流程
4. 禁止隐藏行程价格信息或使用小字号
5. 禁止在行程进行中弹出非安全相关弹窗
