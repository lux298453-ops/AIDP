# 腾讯 (Tencent) 设计风格规范

> 社交绿洲·连接万物·生态织网，主色 #07C160

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **连接**：以人为中心，打破信息孤岛，让沟通与分享无障碍
- **克制**：设计服务于功能，不喧宾夺主，保持界面清爽与专注
- **生态**：尊重平台多样性，一套设计语言适配多端多场景
- **友好**：降低使用门槛，让每个用户都能轻松上手

### 1.2 设计原则
1. **清晰优先**：信息层级分明，核心操作一目了然，减少认知负荷
2. **一致性**：跨产品跨平台保持交互模式与视觉语言统一
3. **高效触达**：最短路径完成目标操作，减少冗余步骤
4. **情感化细节**：在关键节点注入微动效与情感化文案，提升愉悦感
5. **包容设计**：适配不同年龄、能力、设备的用户群体

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F7F7F7 | #111111 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1A1A1A | #E6E6E6 |
| 辅助文字 | #999999 | #8C8C8C |
| 占位文字 | #B2B2B2 | #666666 |
| 分割线 | #ECECEC | #2E2E2E |
| 品牌主色 | #07C160 | #2DC770 |
| 错误色 | #FA5151 | #FF6B6B |
| 警告色 | #FF9C19 | #FFB340 |
| 信息色 | #10AEFF | #40C4FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E6E6E6降低对比度刺激
2. 禁止暗色模式下品牌色直接使用浅色模式色值，必须提亮饱和度保证可识别性
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#111111保持层次感
5. 禁止功能色在暗色模式下降低亮度，应适当提亮保证可读性

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 所有可点击元素必须提供明确的视觉反馈（按压态/涟漪效果）
2. 列表页必须支持下拉刷新与上拉加载更多
3. 表单输入必须提供实时校验与错误提示
4. 页面切换必须使用系统标准转场动画
5. 图标必须使用统一图标库，禁止混用多套图标风格

### 禁止做
1. 禁止在主按钮上使用品牌绿以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮，避免选择困难
3. 禁止使用纯装饰性动画干扰用户操作流程
4. 禁止在列表项中使用超过3种字号，保持层级清晰
5. 禁止底部标签栏图标超过5个，超出需收纳至"更多"
