# 阿里巴巴 (Alibaba) 设计风格规范

> 商业橙光·让天下没有难做的生意，主色 #FF6A00

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **商业赋能**：设计为商业增长服务，每个像素都指向转化与效率
- **数据驱动**：设计决策基于数据验证，而非主观审美
- **开放共生**：平台化设计思维，支持生态伙伴共创
- **确定性**：在复杂商业场景中提供确定性的操作体验

### 1.2 设计原则
1. **自然**：遵循用户直觉，交互方式符合物理世界认知习惯
2. **确定性**：界面状态明确可预期，消除用户犹豫与猜测
3. **意义感**：每项设计都有明确目的，拒绝无意义的装饰
4. **生长性**：设计系统可持续扩展，适应业务不断演进
5. **高效**：缩短操作路径，减少认知负荷，提升商业效率

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #FAFAFA | #141414 |
| 卡片/容器 | #FFFFFF | #1F1F1F |
| 主文字 | #262626 | #E8E8E8 |
| 辅助文字 | #8C8C8C | #8C8C8C |
| 占位文字 | #BFBFBF | #595959 |
| 分割线 | #F0F0F0 | #303030 |
| 品牌主色 | #FF6A00 | #FF8A1A |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |
| 信息色 | #1677FF | #4096FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E8E8E8
2. 禁止暗色模式下直接降低品牌色亮度，应适当提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止功能色在暗色模式下降低亮度，应适当提亮保证可读性

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 所有表单必须提供校验反馈，错误信息紧贴输入框显示
2. 数据表格必须支持排序、筛选、分页
3. 操作按钮位置遵循"主操作右侧/底部"原则
4. 页面必须提供面包屑导航，层级不超过3层
5. 图标必须搭配文字标签，禁止纯图标操作

### 禁止做
1. 禁止在主按钮上使用品牌橙以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰用户操作流程
4. 禁止表格列数超过7列，超出需收纳或分表
5. 禁止使用红色作为非错误/危险操作的按钮色
