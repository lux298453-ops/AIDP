# 零一万物（01.AI）设计规范

> **品牌主色**: `#1A1A2E`（零一黑金）| **平台**: Web | **关键词**: 零一黑金/从0到1/万物生

---

## 一、设计价值观与原则

1. **从0到1**：黑金配色传递从无到有的创造精神，极简中见奢华
2. **万物生**：AI创造万物，界面留白如宇宙虚空，内容如星辰浮现
3. **黑金奢华**：深黑底色+金色点缀，科技感与高级感并存
4. **极简深邃**：去除冗余，界面如深空般宁静，思考如星辰般闪耀

## 八、设计禁忌（Do's and Don'ts）

### Do

- 默认使用暗色界面，黑金配色贯穿全站
- 金色`#D4A017`仅用于主操作和关键强调
- AI气泡使用边框区分，与深色背景有层次
- 代码块使用极深背景+金色行内代码

### Don't

- 禁止金色大面积铺底（视觉刺眼）
- 禁止用户气泡与AI气泡使用相同背景色
- 禁止在暗色界面使用纯白`#FFFFFF`作为大面积背景
- 禁止代码块无语法高亮
- 禁止正文使用`#64748B`以下色值（对比度不足）
