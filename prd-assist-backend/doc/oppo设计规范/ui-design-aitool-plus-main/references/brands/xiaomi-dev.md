# 小米 (Xiaomi) 设计风格规范

> 澎湃橙·感动人心·价格厚道，主色 #FF6700

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **感动人心**：设计追求让用户感动的细节体验，而非堆砌功能
- **价格厚道**：设计体现性价比哲学，简洁高效不浪费每个像素
- **生态互联**：AIoT全场景互联，设计语言跨设备统一
- **极简美学**：少即是多，去除一切非必要装饰

### 1.2 设计原则
1. **极简克制**：界面元素精简到最少，每个元素都有存在理由
2. **功能导向**：设计服务于功能，不追求视觉炫技
3. **一致性**：跨产品跨设备保持统一设计语言
4. **高效直达**：最短路径完成操作，减少层级与步骤
5. **智能感知**：界面主动感知用户意图，提供预测性交互

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #0D0D0D |
| 卡片/容器 | #FFFFFF | #1A1A1A |
| 主文字 | #1A1A1A | #E6E6E6 |
| 辅助文字 | #666666 | #8C8C8C |
| 占位文字 | #999999 | #595959 |
| 分割线 | #EBEBEB | #2E2E2E |
| 品牌主色 | #FF6700 | #FF8A2B |
| 错误色 | #FA5151 | #FF6B6B |
| 警告色 | #FF9C19 | #FFB340 |
| 信息色 | #1989FA | #4DA3FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E6E6E6
2. 禁止暗色模式下品牌橙直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#0D0D0D保持层次感
5. 禁止IoT设备状态色在暗色模式下降低饱和度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 所有IoT设备控制必须提供即时状态反馈
2. 设备列表必须支持按房间/类型分组
3. 表单输入必须提供实时校验与错误提示
4. 页面必须支持MIUI系统级返回手势
5. 图标必须使用MiSans图标库统一风格

### 禁止做
1. 禁止在主按钮上使用品牌橙以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰用户操作流程
4. 禁止底部标签栏图标超过5个
5. 禁止在IoT控制界面使用超过2层嵌套
