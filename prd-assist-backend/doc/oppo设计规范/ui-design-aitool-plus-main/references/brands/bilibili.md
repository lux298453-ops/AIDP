# B站 (Bilibili) 设计风格规范

> Z次元蓝·弹幕宇宙·兴趣部落，主色 #00A1D6

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **Z次元文化**：设计服务于二次元与Z世代文化，年轻有活力
- **弹幕社区**：弹幕是B站灵魂，设计围绕弹幕互动体验
- **兴趣部落**：以兴趣连接用户，设计支持多元圈层文化
- **创作激励**：降低创作门槛，设计鼓励UP主产出优质内容

### 1.2 设计原则
1. **弹幕优先**：弹幕体验不可被遮挡或干扰，弹幕即内容
2. **年轻活力**：视觉语言年轻化，色彩鲜明有活力
3. **圈层归属**：不同分区保持特色，同时统一品牌感
4. **互动丰富**：点赞/投币/收藏/分享一键触达
5. **创作友好**：投稿与创作流程极简高效

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F4F5F7 | #17171A |
| 卡片/容器 | #FFFFFF | #222222 |
| 主文字 | #212121 | #E6E6E6 |
| 辅助文字 | #505050 | #9499A0 |
| 占位文字 | #9499A0 | #61666D |
| 分割线 | #E3E5E9 | #2F2F2F |
| 品牌主色 | #00A1D6 | #23ADE5 |
| 粉色强调 | #FB7299 | #FC8DAA |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E6E6E6
2. 禁止暗色模式下品牌蓝直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止弹幕在暗色模式下使用白色文字，应使用半透明底色保证可读性
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#17171A保持层次感
5. 禁止粉色强调色在暗色模式下降低饱和度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 视频播放器必须支持弹幕开关与弹幕设置
2. 一键三连（点赞/投币/收藏）必须提供快捷操作
3. 视频封面必须16:9比例，清晰无水印
4. UP主信息必须包含粉丝数与投稿数
5. 评论区必须支持按热度/时间排序

### 禁止做
1. 禁止在主按钮上使用品牌蓝以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰视频播放
4. 禁止弹幕遮挡视频关键内容区域
5. 禁止在视频播放中插入不可跳过的广告弹窗
