# 支付宝 (Alipay) 设计风格规范

> 信任蓝·支付无忧·生活服务，主色 #1677FF

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **信任安全**：设计传递金融级安全感，每个操作都让用户放心
- **生活服务**：支付只是入口，设计服务于全场景生活服务
- **普惠金融**：让每个人都能享受便捷的金融服务
- **技术驱动**：AI与技术创新驱动体验升级

### 1.2 设计原则
1. **安全可视**：安全状态始终可见，风险操作明确提示
2. **操作确定**：金融操作必须二次确认，不可逆操作必须警示
3. **信息透明**：金额、费率、规则完全透明展示
4. **效率优先**：常用功能一键触达，支付流程3步完成
5. **包容普惠**：适配全年龄段用户，大字号与无障碍支持

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F2F3F5 | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1D2129 | #E5E6EB |
| 辅助文字 | #6B7785 | #86909C |
| 占位文字 | #A9AEB8 | #5A5A5A |
| 分割线 | #E5E6EB | #2E2E2E |
| 品牌主色 | #1677FF | #408FFF |
| 错误色 | #F53F3F | #FF6B6B |
| 警告色 | #FF7D00 | #FF9A2E |
| 信息色 | #1677FF | #408FFF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E5E6EB
2. 禁止暗色模式下品牌蓝直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止金额数字在暗色模式下降低对比度，必须保持高可读性

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 支付金额必须使用大字号突出显示，字号不小于22px
2. 支付按钮必须固定在页面底部，始终可见
3. 风险操作必须提供二次确认弹窗
4. 交易记录必须提供完整的时间与金额信息
5. 安全中心入口必须始终可访问

### 禁止做
1. 禁止在主按钮上使用品牌蓝以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰支付流程
4. 禁止金额信息使用与正文相同的字号和颜色
5. 禁止在支付确认页面添加非必要干扰信息
