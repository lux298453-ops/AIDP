# 拼多多 (Pinduoduo) 设计风格规范

> 拼团红·百亿补贴·多人成团，主色 #E02E24

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **社交裂变**：设计驱动社交分享与拼团裂变，让用户主动传播
- **百亿补贴**：极致低价是核心吸引力，设计突出价格优势
- **下沉友好**：适配三四线城市用户，大字号大按钮操作简单
- **游戏化**：砍价/签到/抽奖等游戏化设计提升用户粘性

### 1.2 设计原则
1. **价格突出**：价格信息是绝对视觉焦点，字号大颜色红
2. **行动号召**：CTA按钮大而醒目，引导用户立即行动
3. **社交驱动**：拼团/分享入口始终可见，降低分享门槛
4. **游戏化体验**：签到/砍价/抽奖等游戏化元素增加趣味
5. **简单直接**：操作流程极简，减少认知负荷

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #141414 |
| 卡片/容器 | #FFFFFF | #1E1E1E |
| 主文字 | #1A1A1A | #E6E6E6 |
| 辅助文字 | #666666 | #8C8C8C |
| 占位文字 | #999999 | #595959 |
| 分割线 | #EBEBEB | #2E2E2E |
| 品牌主色 | #E02E24 | #F04E45 |
| 错误色 | #FF4D4F | #FF7875 |
| 警告色 | #FAAD14 | #FFC53D |
| 信息色 | #1890FF | #4096FF |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E6E6E6
2. 禁止暗色模式下品牌红直接使用浅色模式色值，必须提亮保证辨识度
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#141414保持层次感
5. 禁止拼团进度条在暗色模式下降低对比度

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 商品价格必须使用品牌红突出显示，字号不小于18px
2. 拼团/分享按钮必须固定在页面底部，高度不小于48px
3. 百亿补贴标签必须使用醒目角标展示
4. 砍价进度必须实时可视化展示
5. 签到入口必须位于首页显著位置

### 禁止做
1. 禁止在主按钮上使用品牌红以外的颜色作为主操作色
2. 禁止弹窗超过3个操作按钮
3. 禁止使用纯装饰性动画干扰拼团流程
4. 禁止商品列表单行超过2个商品卡片
5. 禁止价格信息使用与正文相同的字号和颜色
