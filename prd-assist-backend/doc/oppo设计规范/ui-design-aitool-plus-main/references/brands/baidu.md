# 百度（Baidu）设计规范

> **品牌主色**: `#2932E1`（搜索蓝）| **平台**: Web | **关键词**: 搜索蓝/AI大模型/信息检索

---

## 一、设计价值观与原则

1. **智能普惠**：AI能力人人可用，界面零门槛，交互自然直觉
2. **信息效率**：搜索基因驱动，信息获取路径最短，结果呈现精准
3. **信任可靠**：百度蓝传递专业权威，数据来源可追溯，结果可验证
4. **文心融合**：AI对话与搜索无缝衔接，知识图谱深度赋能

## 八、设计禁忌（Do's and Don'ts）

### Do

- 使用百度蓝`#2932E1`作为唯一品牌强调色
- AI对话中区分用户与AI气泡方向和颜色
- 代码块使用深色背景+等宽字体
- 搜索框聚焦时展示品牌色光晕
- 遵循4px间距基准，保持节奏一致

### Don't

- 禁止在非品牌场景使用百度蓝作为装饰色
- 禁止AI回复气泡使用品牌蓝背景（与用户气泡混淆）
- 禁止代码块使用亮色背景（可读性差）
- 禁止弹窗遮罩透明度低于0.4（内容穿透）
- 禁止正文使用`#999999`以下色值（对比度不足）
