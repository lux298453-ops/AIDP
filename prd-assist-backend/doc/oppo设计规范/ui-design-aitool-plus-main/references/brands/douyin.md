# 抖音 (Douyin) 设计风格规范

> 沉浸黑·全屏世界·记录美好生活，主色 #161823

---

## 一、设计价值观与原则

### 1.1 核心设计价值观
- **沉浸体验**：全屏视频沉浸式浏览，UI退居幕后让内容占满屏幕
- **动感节奏**：设计配合音乐节奏，视觉与听觉同步律动
- **创作赋能**：丰富的拍摄与编辑工具，降低创作门槛
- **算法精准**：基于兴趣的精准推荐，设计服务于信息流效率

### 1.2 设计原则
1. **全屏沉浸**：视频内容占满全屏，UI控件自动隐藏
2. **手势驱动**：上下滑动切换视频，左右滑动进入详情
3. **即时反馈**：每个交互都有即时视觉与触觉反馈
4. **音乐融合**：视觉节奏与音乐节拍同步
5. **创作友好**：拍摄/剪辑/发布流程极简

## 七、暗色模式规范

### 7.1 暗色模式色彩映射
| 色彩角色 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 页面底色 | #F5F5F5 | #0C0C14 |
| 卡片/容器 | #FFFFFF | #1E1E2E |
| 主文字 | #212121 | #E0E0E0 |
| 辅助文字 | #757575 | #8C8C8C |
| 占位文字 | #9E9E9E | #5A5A6E |
| 分割线 | #E0E0E0 | #2A2A3E |
| 品牌主色 | #161823 | #3A3A5C |
| 强调红 | #FE2C55 | #FF4D6D |
| 错误色 | #FF1744 | #FF5252 |
| 警告色 | #FFB300 | #FFD54F |

### 7.2 暗色模式设计禁忌
1. 禁止在深色背景上使用纯白(#FFFFFF)大段文字，应使用#E0E0E0
2. 禁止暗色模式下品牌深色主色需提亮为#3A3A5C保证可识别性
3. 禁止阴影在暗色模式下继续使用，改用边框或亮度差区分层级
4. 禁止大面积使用纯黑(#000000)作为背景，应使用#0C0C14保持层次感
5. 禁止渐变色在暗色模式下降低饱和度，应保持色彩活力

## 八、设计禁忌（Do's and Don'ts）

### 必须做
1. 全屏视频浏览时UI控件必须3秒无操作自动隐藏
2. 所有交互操作必须提供即时触觉反馈（轻触振动）
3. 双击点赞必须配合心形粒子动画
4. 评论输入框必须固定于底部，键盘弹出不遮挡内容
5. 音乐相关操作必须提供节拍可视化反馈

### 禁止做
1. 禁止在信息流中插入不可跳过的全屏广告
2. 禁止使用模态弹窗阻断用户浏览流程
3. 禁止底部标签栏超过5个入口
4. 禁止在视频播放界面叠加超过3个操作按钮
5. 禁止使用低对比度文字影响内容可读性
