### 建议优化项

1. **PRD-05 导出不存在文档返回 500**  
   当前 `GET /api/prd/999/export` 抛出 RuntimeException → 500。建议改为返回 `404 + Result.fail(4101, "文档不存在")`，前端配合展示空状态。

2. **AUTH-08 未认证返回 403 而非 401**  
   Spring Security 默认行为。建议添加 `AuthenticationEntryPoint` 配置，返回标准 401 JSON 响应，提升 API 语义准确性。

3. **未登录时按钮 disabled 状态**  
   所有模块页的"一键生成"按钮当前设为 `disabled`（灰色），终端用户可能误以为是 loading 状态。建议：当输入满足条件时，按钮从灰色变为蓝色 `#409eff`（当前 PRD生成 已实现此逻辑，其他页面可统一）。

4. **前端缺少全局 Loading 骨架屏**  
   AI 生成通常需 10~60 秒，当前仅有 `el-progress` 进度条。建议为预览区添加骨架屏 (Skeleton)，提升等待体验。

5. **异常状态下 SSE 断线无自动重连**  
   前端 `EventSource` 的 `onerror` 直接关闭连接。建议添加指数退避重连逻辑（如 2s→4s→8s→最多3次），防止网络抖动导致进度丢失。
